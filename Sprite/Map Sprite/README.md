# 맵 그림 원본

맵 그림의 **원본**을 지역별로 모아 두는 곳입니다. Unity 프로젝트(`Assets`) 밖이라 여기 넣은 그림은 게임에 바로 나오지 않습니다.
초록 배경 지우기, 크기 맞추기, 이음새 다듬기를 거친 뒤 `Assets/Resources/` 아래로 옮겨야 게임에 쓰입니다.

## 폴더

번호는 게임 진행 순서입니다.

| 폴더 | 지역 |
|---|---|
| `00_WorldMap` | 월드맵 |
| `01_Village` | 마을, 이시스의 연습장 |
| `02_TutorialForest` | 튜토리얼 숲 |
| `03_DarkForest` | 어둠의 숲 |
| `04_Plains` | 광활한 평야 |
| `05_Ruins` | 잊혀진 폐허 |
| `06_BlueSea` | 푸른 바다 (추격전, 아쿠아 투기장 포함) |
| `07_Ensroom` | 엔스룸 마을 |
| `08_Heaven` | 천상의 계단, 신전, 이리아의 성소 |
| `09_HillOfDespair` | 절망의 언덕 |
| `99_Common/Portals` | 여러 지역에서 쓰는 포탈 그림 |
| `99_Common/RoomDevices` | 여러 지역 방에서 쓰는 장치 시트 (전멸방 철문, 철창, 부서지는 벽, 종·조개·룬 스위치, 벽화, 봉인 문, 부서진 조각) |

지역 폴더 안은 이렇게 나눕니다.

| 하위 폴더 | 넣는 것 |
|---|---|
| `Original` | 예전에 쓰던 한 장짜리 배경 그림 |
| `Parallax` | 시차 배경 층. `1_sky`, `2_far`, `3_near`, `4_ground` 순서로 이름을 붙입니다 |
| `Platforms` | 밟을 수 있는 발판을 모아 그린 시트 |
| `Props` | 맵마다 다르게 배치할 소품 낱장 (고목, 석등, 수정, 바위 등) |
| `Edge` | 방 테두리 그림 (벽·천장 타일, 천장 덩굴 띠, 구멍 모서리, 통로 문틀, 구멍 양쪽 절벽, 늘어진 장식). 평야·폐허·바다 |
| `RoomDevices` | 그 지역에만 쓰는 방 장치 시트 (어둠의 숲: 썩은 가지, 덮개, 봉인의 열쇠, 봉인 문, 수정 스위치) |

## 게임에 들어간 뒤의 위치

| 종류 | 게임 폴더 | 불러오기 설정 |
|---|---|---|
| 시차 배경 층 | `Assets/Resources/Backgrounds/Parallax/지역/` | 1칸 = 135px, 아래 가운데 기준점 (자동) |
| 배경 소품 | `Assets/Resources/Backgrounds/Parallax/지역/Props/` | 시차 배경과 같은 설정 (자동) |
| 발판 | `Assets/Resources/Art/Props/지역/` | 1칸 = 240px, 아래 가운데 기준점 (자동) |
| 방 테두리 | `Assets/Resources/Art/Props/PlainsEdge/`, `RuinsEdge/`, `SeaEdge/` | 1칸 = 135px, 아래 가운데 기준점 (자동) |
| 방 장치 | `Assets/Resources/Art/Props/RoomDevices/`, `ForestDevices/` | 1칸 = 135px, 아래 가운데 기준점 (자동) |

지금 시차 배경이 들어간 지역은 어둠의 숲(`Parallax/Forest`)뿐입니다.

## 층별 크기 (1칸 = 135px 기준)

| 층 | 크기 | 배경 |
|---|---|---|
| `1_sky` | 2400 × 1600 | 꽉 찬 그림. 맨 위 200px은 거의 단색 |
| `2_far` | 2048 × 1100, 좌우 이음 | 초록 단색 (#00FF00) |
| `3_near` | 2048 × 1400, 좌우 이음 | 초록 단색 |
| `4_ground` | 2048 × 320, 좌우 이음, 밟는 선은 위에서 약 90px | 초록 단색 |
| 소품 | 물체마다 다름, 밑면이 그림 맨 아래에 닿게 | 초록 단색 |
| 안개 띠 | 2048 × 300, 좌우 이음 | 검정 단색 |
